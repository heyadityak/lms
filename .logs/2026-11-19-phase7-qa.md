## Bugs found (ranked by severity; all have a red `#[Group('known-bug')]` test)
1. **Medium — 404 body is an id-existence oracle and leaks class names.** `app/Exceptions/ProblemJsonRenderer.php:60` passes the framework message through: a nonexistent id gives `detail: "No query results for model [App\Models\LeaveRequest] <id>"`, a hidden-but-existing id gives `detail: "Not Found"`. Expected identical bodies (API_GUIDELINES §5 "so ids cannot be probed"). Test `LeaveApiContractTest::test_404_body_does_not_reveal_whether_an_id_exists_or_internal_class_names`.
2. **Medium — deactivated user's token still provisions.** `app/Auth/KeycloakJwtGuard.php:58` calls `provision()` before the `is_active` check at :59, so a refused (401) call still writes `last_login_at`, fills `date_of_joining` from the claim and **grants entitlement** (3 ledger rows) to an inactive user (USE_CASES §3.9 "excluded from accrual"). Same order in the web callback. Expected: no writes for inactive users. Test `JwtClaimProbeTest::test_deactivated_users_token_has_no_provisioning_side_effects`.
3. **Medium — actions on an invisible request answer 403, not 404.** `app/Policies/LeaveRequestPolicy.php:38` (`decide`) and `:48` (`cancel`) deny with 403 even when `view` would 404, so a stranger can probe ids via POST approve/reject/cancel. Expected 404 (API_GUIDELINES §5). Note: `LeaveApiTest::test_self_approval_and_non_report_are_forbidden_hr_can_approve` (line ~91) asserts 403 for a non-report manager and must change with the fix. Test `LeaveRulesEdgeTest::test_actions_on_an_invisible_request_are_404_not_403`.
4. **Low/medium — cancel policy TOCTOU.** `LeaveRequestPolicy.php:50` reads the unlocked route-bound status; `CancelLeaveRequest.php:23` re-checks only the state machine under the lock. An owner cancelling a backdated pending request while the manager approves it ends up cancelling leave that has already started (200, reversal written). Expected 403/409 and the request stays approved. Fix: re-evaluate the "started" rule on the locked row. Test `LeaveRulesEdgeTest::test_owner_cancel_racing_an_approval_cannot_cancel_started_leave`.
5. **Low — employee-role "manager" can approve.** `app/Services/ApproverResolver.php:33` allows any `manager_id` holder; openapi `x-roles` for approve/reject = `[manager, hr_admin]`, and `/approvals` already 403s them. Expected 403. (Domain flagged this in phase 6; needs an architect call if the current behaviour is intended.) Test `LeaveRulesEdgeTest::test_employee_role_user_set_as_manager_cannot_approve`.
6. **Low — NUL byte silently truncates text.** `app/Http/Requests/StoreLeaveRequestRequest.php:28` accepts `"Trip\u0000home"`; the 201 response echoes the full string but pdo_pgsql stores `"Trip"`. Expected 422. Applies to every free-text field. Test `LeaveApiContractTest::test_nul_byte_in_reason_is_refused_not_silently_truncated`.
7. **Low — `date_of_joining` claim with trailing newline → 500 on every call.** `app/Auth/KeycloakUserProvisioner.php:99` regex `$` matches before `\n`, then `CarbonImmutable::createFromFormat` (:102) throws "Trailing data". Expected: claim ignored (use `\z` or the `D` modifier, catch `InvalidFormatException`). Test `JwtClaimProbeTest::test_joining_date_claim_with_trailing_newline_is_ignored_not_a_500`.
8. **Low — huge `page[number]` wraps to page 1.** `app/Http/Requests/ListLeaveRequestsRequest.php:39` has no upper bound; `page[number]=9223372036854775807` overflows the offset and returns the first page's data. Expected an empty page (or 422 with a max). Test `LeaveApiContractTest::test_huge_page_number_does_not_wrap_around_to_the_first_page`.
